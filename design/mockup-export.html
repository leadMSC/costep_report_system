처음 열 때 체크 상태

  • 분야: 지금 보고 있는 분야만
  • 서식: 1~4 모두
  • 다음에 열면 마지막 선택을 기억

출력 옵션 (제안 — 넣고 뺄 것 골라 주세요)

  • 파일 묶음 (PDF·Docs): 한 파일 / 서식마다 따로
  • 직인 넣기: 서식1 발신란의 펌 직인
  • 쪽 번호: 아래 가운데 「1 / 8」
  • 컬러 (인쇄만): 컬러 / 흑백
  • 부수 (인쇄만)
  • 양면 인쇄 (인쇄·PDF): 단면 / 양면 — 양면이면 서식마다 앞면에서 시작하도록 빈 쪽을 자동으로 끼움. 브라우저가 프린터의 양면 설정을 대신 켤 수 없어서, 인쇄 창의 「설정 더보기 → 양면 인쇄」를 켜라고 안내

파일 이름

  • 한 장: [한빛정밀] - 가나경영 경영리포트_경영개선_서식2 결과보고서.pdf
  • 분야 하나: [한빛정밀] - 가나경영 경영리포트_경영개선.pdf
  • 분야 여럿: [한빛정밀] - 가나경영 경영리포트.pdf
