# 대시보드 갱신 방법

- 대시보드: https://claude.ai/artifact/Fna3M89LgQdfypWQJHPmMf
- 원본 시트(소유: 운영자 개인 구글 계정): https://docs.google.com/spreadsheets/d/1UaD5dEWwA5Iy3ifw4z7cJKSD8VsGLXDP64P9U7HFhVY/edit
- 탭 7개(defects, scenarios, pdf_compare, pdf_checks, roadmap, requests, actions) = 대시보드 자료 7개. 탭 이름·첫 줄(열 이름)은 바꾸지 않는다.

## 구조
대시보드는 시트를 읽어 **저장해 둔 사본**을 보여준다(보는 사람은 구글 연결 없이 링크만 열면 됨).
각 자료에는 시트를 읽는 요청(Google Sheets `get_values`, 범위 `탭!A1:끝열`)이 저장돼 있다.

## 갱신 절차 (Claude 가 수행)
1. 탭마다 Google Sheets `get_values` 로 읽는다.
2. 첫 줄을 열 이름으로 행 객체 배열로 바꾸고, 숫자 칸은 숫자로 바꾼다 (대시보드 loader 와 같은 규칙).
3. `dashboard/data/<탭>.json` 으로 저장 → Artifact 에 asset 으로 올림.
4. ArtifactData `update` 로 `datasets/<탭>` 의 `source.url`, `source.name`, `updated`, `lastAttempt` 를 갱신.
5. 작업로그에 운영 항목으로 기록.

자동 갱신: 예약 작업 `costep-dashboard-refresh-2` (매일 07:30경 — 실제 07:42, Claude 앱이 켜져 있을 때 실행 — 꺼져 있으면 다음 실행 때). 사이드바 Scheduled 에서 관리. 시트는 읽기만 하고 git 커밋은 하지 않으므로, 로컬 `dashboard/data/*.json` 변경은 다음 작업 때 함께 커밋한다.
