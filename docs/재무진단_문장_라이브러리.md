# 재무진단 자동 문장 라이브러리

앱 안 `FA_TEXT`(코스텝_경영진단_리드디벨롭.html)에서 자동 생성한 목록입니다. 문장을 고치려면 FA_TEXT 를 고치고 이 문서를 다시 만듭니다.

## 판정 방법

- 영역마다 지표 3개를 비교 기준(업종평균이 있으면 업종평균, 없으면 기준선)과 견줘 지표별로 양호 2 / 보통 1 / 미흡 0 점(기준의 ±10% 안은 보통).
- 영역 평균 1.4 이상 양호, 0.7 이상 보통, 그 아래 미흡. 지표가 2개 미만이면 판단 보류.
- 같은 계산을 전년에도 해서 평균이 0.34 이상 오르면 개선, 내리면 악화, 그 사이는 유지.
- 특수 상황이 등급을 고정: 완전 자본잠식·이자보상배수 3년 연속 1 미만 = 미흡, 부분 자본잠식 = 최고 보통.
- 문장 = 특수 상황 문장(해당될 때, 앞) + 기본 문장. 자리표시: {best} 가장 좋은 지표, {worst} 가장 약한 지표(값과 비교 기준 함께), {basis} 업종평균/기준선, {trend} 흐름 문구.

## 기본 문장 (영역 × 등급 × 흐름)

### 성장성

| 등급 | 흐름 | 문장 |
|---|---|---|
| 양호 | 개선 | 매출과 자산이 {basis}보다 빠르게 늘어 성장 흐름이 뚜렷하고, {trend}. 확장 자금 수요를 설명하기 좋은 상태입니다. |
| 양호 | 유지 | {best} 등 성장 지표가 {basis}을 웃돌아 꾸준히 성장하고 있습니다. |
| 양호 | 악화 | 성장 지표는 {basis}을 웃돌지만 증가 폭은 전년보다 줄었습니다. 성장 둔화 요인을 점검할 필요가 있습니다. |
| 보통 | 개선 | 성장 지표가 {basis}과 비슷한 수준이며, {trend}. |
| 보통 | 유지 | 성장 지표가 {basis}과 비슷해 보통 수준의 성장 역량을 보이고 있습니다. |
| 보통 | 악화 | 성장 지표가 {basis} 수준이지만 전년보다 둔화되었습니다. {worst}의 원인을 확인할 필요가 있습니다. |
| 미흡 | 개선 | {worst} 등 성장 지표가 {basis}에 못 미치지만, {trend}. 회복 흐름을 이어갈 판로 확대 계획이 필요합니다. |
| 미흡 | 유지 | {worst} 등 성장 지표가 {basis}에 못 미쳐 성장 역량이 낮은 편입니다. 신규 판로 확보가 과제입니다. |
| 미흡 | 악화 | 성장 지표가 {basis}에 못 미치고 전년보다 더 둔화되었습니다. 매출 감소 원인과 대응 계획을 먼저 정리해야 합니다. |

| 영역 | 상황 | 문장 |
|---|---|---|
| 수익성 | loss_turn | 당기에 영업손실로 돌아섰습니다(영업이익 {op}). 적자 원인과 흑자 회복 계획이 필요합니다. |
| 수익성 | loss_cont | 영업손실이 이어지고 있습니다(영업이익 {op}). |
| 수익성 | profit_turn | 전년 영업손실에서 당기 흑자로 돌아섰습니다(영업이익 {op}). |
| 재무구조 | capital_full | 자본총계가 0 이하인 완전 자본잠식 상태로, 정책자금·보증 신청이 제한될 수 있습니다. |
| 재무구조 | capital_part | 자본금보다 자본총계가 적은 부분 자본잠식 상태입니다(잠식률 {impair}%). 일부 정책자금은 신청이 제한될 수 있습니다. |
| 부채상환능력 | icr_3y | 이자보상배수가 3년 연속 1 미만으로, 한계기업으로 분류될 수 있습니다. |
| 부채상환능력 | icr_1 | 이자보상배수가 1 미만({icr}배)이라 영업이익으로 이자를 다 갚지 못하는 구간입니다. |
| 성장성 | sales_down_2y | 매출이 2년 연속 감소했습니다({sg}). 판로·제품 경쟁력 점검이 우선입니다. |
| 성장성 | sales_jump | 매출이 전년보다 {sg} 늘어 빠르게 성장하고 있습니다. 늘어난 매출에 맞는 운전자금 확보가 필요할 수 있습니다. |
| 활동성 | ar_slow | 매출채권 회수에 평균 {ardays}일이 걸려 운전자금 부담이 큽니다. |
| 공통 | no_data | 판단에 필요한 재무 자료가 부족합니다. 3개년 재무제표를 올리면 판정됩니다. |
