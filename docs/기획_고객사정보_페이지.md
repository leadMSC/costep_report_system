# 고객사 정보 페이지 재기획 (2026-10-21)

## 배경
- 요청: 참고 화면(「01 기업 일반 현황 및 핵심 인프라」)처럼 고객 정보를 한 페이지에서 받되, **새 폼을 덧붙이지 말고 기존 칸과 겹치는 것은 한 번만 적게** 페이지를 다시 짠다. 업종은 자유 기재(주유소·화훼처럼 정해진 10개 업종에 없는 경우), 칸마다 예시, 펼치면 대표자 주민등록번호 칸, 서류 업로드로 자동 채우기, 항목명·내용을 직접 적는 「기타」 칸.
- 현황(실측): 입력 칸 148개 / 8단계. 고객사 정보 단계 13칸, 나머지 기업 정보가 진단 대상·거래처·인증·실태·재무·업종 특화·사업계획에 흩어져 있고 같은 내용을 두세 곳에서 묻는다.
- 원칙: ① 한 사실은 한 칸(나머지 단계·서식은 그 칸을 읽기만) ② 불변 → 가변 순서 ③ 서류로 채울 수 있는 칸은 서류 먼저, 사람은 빈칸·확인만 ④ 기존 저장 자료는 새 칸으로 자동 이전(버전 올림) ⑤ A4 서식 출력은 지금 모양 유지.

## 6. 결정 (2026-10-21 사용자)
1. 주민등록번호: 13자리 전체 칸(3절).
2. 업종: '기타' 없음 — 모든 업종을 한국표준산업분류(KSIC)로 분류. 입력은 사업자등록증의 업태·종목 그대로, 입력하면 KSIC 코드를 추천(8절).
3. NICE·KCB·상시 근로자 수: 규모와 무관하게 모두 받음 — 고객사 정보로 이동.

## 7. 진행 순서(승인 후)
1. 칸 사전(FIELD_REGISTRY)에 중복 통합 결과 반영 + 저장 자료 v2 이전 함수(옛 칸 값 → 새 칸, 손실 없음)
2. 고객사 정보 페이지 재배치(위 4) — impeccable(Operate) 로 배치, 기존 색·글꼴 유지
3. 새 칸 + 서류 연결(업태/종목 분리, 성별 자리, 주주 목록, 임대차→점유)
4. 기타 항목 행 + 업종별 예시 칩, 서식2 '기타' 표 출력
5. 업종 특화·실태·사업계획 단계에서 중복 칸 제거(읽기 전용 표시로 대체)
6. 검증: 시나리오·PDF·break-ui(긴 항목명·행 20개)·옛 저장 자료 불러오기 이전 시험

## 8. 업종 = 한국표준산업분류(KSIC) 체계
### 8-1. 기준
- 제11차 한국표준산업분류(2024-07-01 시행 — 2차 출처 확인, 구현 때 통계청 고시로 재확인). 대분류 A~U(21) → 중분류(2자리) → 소분류(3) → 세분류(4) → 세세분류(5자리). 앱은 **세세분류 5자리**를 주업종으로 저장(`corp_ksic`, 이름·경로 함께).
- **업태·종목과 표준산업분류코드는 다른 칸**(사용자 지시 2026-10-21): 업태·종목은 사업자등록증 원문 그대로 `corp_biz_up`·`corp_biz_item` 에, 코드는 추천을 거쳐 따로 확정.
- 사업자등록증의 업태·종목은 국세청 업종분류(6자리 업종코드) 체계의 글이고, 국세청 업종코드는 KSIC 세세분류와 연결돼 있다(예: 011001 → 01121 채소·화훼작물 및 종묘 재배업). 그래서 **사업자등록증 글 → 국세청 업종 → KSIC** 순으로 맞추는 것이 가장 정확하다.

### 8-2. 추천 방식(브라우저 안, 서버·외부 호출 없음)
- 자료(앱에 내장): ① KSIC 11차 세세분류 목록(코드·이름·상위 경로) ② 국세청 업종코드–KSIC 연계(업태명·종목명/적용 범위 낱말 → KSIC). 출처: 통계분류포털(kssc.mods.go.kr)·국세청 업종코드 고시 — 구현 첫 단계에서 원본 파일을 받아 변환(코드 연계표 공개 페이지에서 귀속연도 2025, 차수 11 확인).
- 매칭: 종목 글을 낱말로 나눠(쉼표·'및'·괄호) 국세청 종목명·적용범위·KSIC 이름과 겹치는 정도로 점수 → 업태(제조업·도매 및 소매업 등)로 대분류를 좁혀 동점 정리 → 상위 3개를 근거(일치한 낱말)와 함께 추천. 종목이 여러 개면 첫 종목을 주업종 후보로, 나머지는 부업종으로 표시.
- 화면: 추천 칩을 누르면 확정. 맞는 게 없으면 「직접 검색」(코드·이름). 확정 전에는 노란 표시, 서류 업로드로 업태·종목이 채워지면 추천이 바로 다시 뜬다.
- 예(구현 때 고시로 코드 확인): 종목 '주유소' → G 도매 및 소매업 › 47 소매업 › 연료 소매(차량용 주유소 운영) / 종목 '화훼' + 업태 '농업' → A 01121 채소·화훼작물 및 종묘 재배업, 업태 '도매' → G 46 화훼류 도매, 업태 '소매' → G 47 화초·식물 소매.

### 8-3. 코드 하나로 자동으로 정해지는 것
| 무엇 | 지금 | KSIC 로 바뀌는 점 |
|---|---|---|
| 업종 특화 질문 | 10개 업종 버튼 중 하나 | 대분류 21개 모두 기본 질문 묶음 + 자주 나오는 세분류는 추가 질문(예: 연료 소매 → 석유판매업 등록·위험물 저장소 허가·정유사 공급계약·월 판매량 / 화훼 재배 → 재배 면적·시설(온실)·공판장 거래·계절 편차). 기존 10개 묶음은 해당 대분류·중분류에 그대로 연결 |

| 지원사업·정책자금 매칭 | 업종 키워드 | 공고의 업종 조건·융자 제외 업종(유흥·사행·부동산 임대 등)을 코드로 대조해 '제한 업종' 경고 |
| 서식 출력 | '업종 미지정' 또는 자유 글 | 서식1·2 기업 개요에 「주업종: 코드 이름」 |

### 8-4. 기존 자료 이전
- 저장된 고객의 `corp_biz_type`·주업종 버튼 값으로 추천을 돌려 후보를 띄우고(자동 확정하지 않음), 확정 전까지 기존 업종 묶음을 그대로 쓴다.
